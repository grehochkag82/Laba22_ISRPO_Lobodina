## Описание проекта

Проект представляет собой набор из двух небольших интерактивных приложений, реализованных на чистом JavaScript (ES6) с использованием HTML5 и CSS3:

1. **Калькулятор** – выполняет базовые арифметические операции с валидацией ввода и обработкой ошибок.
2. **Крестики-нолики** – классическая игра для двух игроков с определением победителя и возможностью сброса.

Оба приложения используют модульную архитектуру (ES6 modules), стилизованы с помощью CSS Grid/Flexbox и адаптированы для современного браузера.

## Функциональность

### Калькулятор

- **Поддерживаемые операции:**  
  `+`, `-`, `*`, `/`, десятичная точка (`.`).

- **Возможности:**
  - Ввод чисел и операторов последовательным нажатием кнопок.
  - Кнопка `C` – полная очистка выражения.
  - Кнопка `=` – вычисление результата.
  - Отображение текущего выражения на дисплее.

- **Ограничения и валидация:**
  - Запрещены два оператора подряд (например `5++3`).
  - Нельзя начинать выражение с оператора (кроме унарного минуса? – в данной реализации унарный минус не поддерживается).
  - Запрещено более одной точки в пределах одного числа (например `5.2.1`).
  - Оператор не может быть последним символом перед вычислением.
  - Деление на ноль перехватывается и выводится `Ошибка`.

- **Обработка ошибок:**
  - При некорректном выражении (синтаксическая ошибка, деление на ноль) на дисплее появляется сообщение `Ошибка`.
  - Состояние ошибки сбрасывается автоматически при следующем корректном действии (или нажатии `C`).

### Крестики-нолики

- Игровое поле 3×3.
- Два игрока по очереди ставят `X` и `O`.
- Автоматическое определение победителя (горизонталь, вертикаль, диагональ).
- Определение ничьей (все клетки заполнены, победитель не найден).
- Кнопка сброса для начала новой игры.
